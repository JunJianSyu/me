## 一、下载 X-Lite 26H1 镜像

目前 X-Lite 主要通过网盘分发：

- **百度网盘**：`https://pan.baidu.com/s/1Aj13l8D_kTzWtRDhkrf6dQ?pwd=8888`（提取码 `8888`）
- 文件名：`Windows X-Lite Optimum 11 26H1 V3 x64.iso`
- 版本选择：日常用选 **Optimum 版**（功能齐全 + 轻量），不要选 Micro 版（砍太多，日常不便）

下载后核对文件完整性，放到你制作启动盘的电脑上备用。

## 二、制作 U 盘启动盘

推荐用 **Ventoy**（一个 U 盘可以放多个镜像，方便以后换系统）。

### 方法 A：Ventoy（推荐）

1. 到 Ventoy 官网下载：`https://www.ventoy.net`
2. 插入 U 盘（8GB 以上，会格式化，提前备份 U 盘数据）
3. 打开 Ventoy → 选择 U 盘 → 点击 Install
4. 安装完成后，U 盘会变成一个普通可读写分区
5. 把下载好的 `.iso` 文件**直接复制**到 U 盘根目录即可

### 方法 B：Rufus（更传统）

1. 到 Rufus 官网下载：`https://rufus.ie`
2. 插入 U 盘，打开 Rufus
3. 设备：选你的 U 盘
4. 引导类型：选择 → 加载 X-Lite 的 ISO 文件
5. 分区类型：**GPT**
6. 目标系统：**UEFI（非 CSM）**
7. 文件系统：**NTFS**
8. 点击开始，等待 5-10 分钟

## 三、Steam Deck BIOS 设置

1. 关机状态下，同时长按 **音量减（Volume Down）+ 电源键**
2. 松开电源键，保持按住音量减，直到进入 BIOS
3. 进入 BIOS 后：
   - **Security Boot** → 改为 **Disabled**
   - **Boot Manager** → 找到你的 U 盘，设为第一启动项
4. 保存并重启（F10 Save & Exit）

## 四、安装系统

1. 从 U 盘启动，进入 Windows 安装界面
2. 语言、区域选**中文（简体）**
3. 到分区界面：
   - 如果是全新安装，选中目标硬盘 → **格式化** → 选择分区安装
   - 如果是双系统保留 SteamOS，只格式化分配给 Windows 的分区
4. 点击安装，等待 15-25 分钟，系统会自动重启 2-3 次
5. 按提示创建本地账户（建议跳过网络连接，用离线账户）

## 五、进系统后必做设置

### 1. 修复中文显示

设置 → 时间和语言 → 语言和区域 → 管理语言设置 → 系统区域设置 → 改为 **中文（简体，中国）** → 重启

### 2. 添加输入法

任务栏语言栏 → 添加 → **中文（简体）微软拼音**

### 3. 安装浏览器

X-Lite 已移除 Edge，提前准备好 **Chrome** 离线安装包，用 U 盘拷进去安装。

### 4. 系统激活（可选）

以管理员身份打开 PowerShell，执行：

```powershell
irm https://get.activated.win | iex
```

弹出菜单中选择 **HWID**，等待激活完成。

### 5. Windows 更新管理

X-Lite 默认关闭了自动更新。建议装 **InControl** 工具来管理更新开关：
- 需要更新时点 **Release Control**（启用）
- 不想被更新打断时点 **Take Control**（禁用）

## 六、Steam Deck 必装软件清单

装完系统后，以下软件按顺序安装，才能获得完整的掌机体验：

### 核心驱动层

| 软件 | 功能 | 来源 |
|------|------|------|
| **AMD 显卡驱动** | GPU 驱动，必须先装 | AMD 官网搜索 Steam Deck APU 驱动包 |
| **Wi-Fi 驱动** | 无线网卡 | Valve 官方驱动包 |
| **音频驱动** | 扬声器和耳机口 | Valve 官方驱动包 |
| **SD 卡驱动** | microSD 读卡器 | Valve 官方驱动包 |

> Valve 官方提供了 Steam Deck Windows 驱动整合包，搜索"Steam Deck Windows Drivers"可找到官方下载页。

### 掌机体验核心工具

| 软件 | 功能 | 说明 |
|------|------|------|
| **Steam Deck Tools** | 风扇控制 + 性能监控 + TDP 调节 + 手柄映射 | 必装，GitHub 开源项目，装完后系统托盘出现图标 |
| **HandheldCompanion** | 功耗控制 + FPS 显示 + 按键映射 + 陀螺仪 + GUI 界面 | 功能最全的掌机工具，需联网下载 |
| **SWICD** | 手柄映射（虚拟 Xbox 360 手柄） | 适合不想折腾的用户，开箱即用 |

三个手柄工具选一个即可，推荐组合：

- **Steam Deck Tools**（风扇 + TDP + 性能监控）+ **HandheldCompanion**（按键映射 + 陀螺仪）

### Steam Deck Tools 详细配置

装完后逐项设置：

**风扇控制**：右键托盘图标 → 选 **SteamOS 模式**（完全复刻原系统风扇算法，散热和噪音平衡最好）

**性能监控**：开启覆盖层，选 **FPS + 电池模式**，游戏时实时显示帧率和温度

**TDP 控制**：根据场景设档位：
- 独立游戏 / 2D 游戏：**8W**（省电续航长）
- 中等 3A 游戏：**12-15W**
- 高负载 3A：**15-22W**（注意散热）

**手柄模式**：选 **X360 模拟模式**，兼容所有支持 Xbox 手柄的游戏

### HandheldCompanion 详细配置

**陀螺仪**：在控制器设置中开启陀螺仪映射，用于射击游戏的瞄准辅助

**屏幕旋转**：如果装完系统屏幕方向是竖的，HandheldCompanion 可以强制设置为横屏

**按键映射**：为每个游戏单独配置快捷键组合（如 L4+R4 截图、L5 切 TDP 档位等）

### 实用辅助工具

| 软件 | 功能 |
|------|------|
| **Autologon** | 开机自动登录，免每次输密码 |
| **AutoEndTasks** | 关机时强制关闭无响应程序，避免卡住 |
| **HWiNFO** | 硬件温度传感器监控（比 Steam Deck Tools 更详细的传感器读数） |
| **火绒安全** | 轻量杀毒（X-Lite 关了 Defender，需要替代防护） |
| **Steam 客户端** | 大屏模式，游戏库管理和启动 |
| **DirectX 修复工具** | 部分游戏缺 DLL 时修复（X-Lite V3 已集成，备用） |

## 七、安装顺序总结

```
1. 装系统 X-Lite 26H1
2. 修复中文 + 装输入法 + 装浏览器
3. 装 AMD 显卡驱动（必先）
4. 装 Wi-Fi / 音频 / SD 卡驱动
5. 装 Steam Deck Tools（风扇 + TDP + 性能监控）
6. 装 HandheldCompanion（手柄 + 陀螺仪 + 屏幕方向）
7. 装 Steam 客户端 → 切大屏模式
8. 装 Autologon + AutoEndTasks + 火绒
9. 导入游戏 → 开玩
```

装到这一步，你的 Steam Deck 就是一台完整的 Windows 掌机了。系统只占 5-7GB，内存占用 1.1-1.7GB，剩余空间和性能全部留给游戏。

## 安装教程

### 第一步：装机前准备

1. 下载 ISO 后校验哈希值，不一致则删除重下
2. 准备一个 8GB+ U 盘
3. 下载 **Rufus** 或 **Ventoy** 制作启动盘
   - 分区类型选 **GPT**，目标系统选 **UEFI**（老 BIOS 机器选 MBR）
4. 进 BIOS 将 U 盘设为第一启动项，**关闭 Secure Boot** 以防被拦截
5. **备份重要数据**——这是最后底线

### 第二步：安装系统（两种方式）

**方式一：U 盘直装（简单）**
1. U 盘启动进入 Windows 安装向导
2. 选"自定义安装"
3. 手动选择系统分区（建议先格式化目标分区）
4. 等待释放镜像，耗时约 25-35 分钟

**方式二：PE + WinNTSetup（进阶）**
1. 进 PE 系统
2. 打开 WinNTSetup 工具
3. 三个核心设置：选 install.wim 路径 → 选引导磁盘（通常 EFI 分区）→ 选安装位置
4. 点安装，等待完成
5. 优势：可顺手格式化分区、清理残留引导、用 DiskGenius 做分区对齐

### 第三步：装完系统的"三件套"补环境

按固定顺序安装：

1. **网卡驱动**（最优先，否则无法联网）— 提前备好离线驱动包或官网驱动
2. **运行库合集** — 一次性装齐 VC++ 2015-2022（32/64 位）、.NET 4.8、DirectX 组件
3. **输入法和浏览器** — 系统默认无 Edge 和微软拼音，需自备 Chrome/Firefox 安装包和第三方输入法

## 避坑指南

| 坑 | 解决方案 |
|----|---------|
| 安装卡住/报错 0x8007025D | 镜像损坏或 U 盘问题，重新校验哈希，换 USB 2.0 口重试 |
| 错误 0xC0000005 | 引导配置问题，从 PE 重做引导、修复 ESP 分区 |
| 打印机/蓝牙不认 | Print Spooler 服务检查；蓝牙可能需外接 USB 适配器；网卡务必备离线驱动 |
| 软件报缺 DLL | 装运行库合集，**不要**去 DLL 下载站单文件丢 system32 |
| 系统更新 | 默认被移除，**不建议**重新开启，更新会破坏精简状态 |
| 安全防护 | Defender 被移除，建议装轻量第三方安全软件，**不要**在此机器登录网银/放重要文件 |

**额外提示**：如果还在用机械硬盘，光装精简系统改善有限。最优组合是 **精简系统 + SSD**，才能发挥最大效果。

## 版本选择建议

| 版本 | 适合 |
|------|------|
| **Optimum**（Win11 26H1） | 日常使用+游戏，保留微软商店，大多数人的首选 |
| **Micro**（Win11 26H1） | 4GB 内存老设备，空载内存低至 800MB |
| **Optimum10 Pro**（Win10） | 更适合老旧设备，基于 Win10 内核，兼容性更好 |

如果你是给之前聊到的那台闲置 PC（用来做旁路由的那台）装系统，X-Lite Optimum 版是个不错的选择。不过那台机器如果主要跑软路由，iStoreOS 会更合适；X-Lite 更适合作为日常使用或游戏机的系统。
